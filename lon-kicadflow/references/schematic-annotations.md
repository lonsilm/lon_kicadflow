# 原理图逐器件详细中文注释规范

## 目标与适用范围

用户明确要求：**注释详细、解释全中文、几乎每一个器件都有说明，必须讲清具体功能，不能让读图者猜。** 本规范用于新绘制、添加器件、功能修改和全面完善原理图，属于设计完成标准，不是有空才做的润色。

新图或全面完善任务以所有实际器件可追溯为目标，不任意设定“写到九成就行”的比例。局部变更至少完成本次新增/受影响器件及相关回路的注释，并说明范围外仍缺什么；不借此改动用户未授权的页面或PCB。仅查询、审查时检查和报告，不自动写入原理图。

## 全中文的具体含义

- 标题、用途、原理、操作步骤、默认状态、注意事项和待确认事项用中文写完整句子；不要直接把英文器件描述粘过来。
- 位号、真实网名、引脚名、料号、封装标识、数值和单位保留工程原始写法。`RESET_N`可说明为“低电平有效的复位信号”，不能擅自把网络重命名成中文。
- 缩写首次出现时解释，例如“低压差线性稳压器（LDO）”“模数转换器（ADC）”“串行调试接口（SWD）”；后文可用已经解释过的缩写。
- 不翻译制造商型号、脚号或文件路径，也不把代码/协议标识改成不存在的中文名称。“全中文”要求的是解释可读，不是破坏设计标识。
- 电气术语应继续说明它在本电路里的作用，不以一堆缩写替代解释。

## 每个器件需要回答的问题

围绕实际连接写，内容长度按功能复杂度安排。简单器件也要有具体内容，复杂器件分层说明，不能为了省版面只写类别。

| 问题 | 应写出的信息 |
|---|---|
| 这是谁 | 位号；必要时值、精确型号、单元或脚号 |
| 在这里做什么 | 为哪个芯片、哪条供电或哪路信号服务，承担哪项具体功能 |
| 接在哪里 | 输入/输出/两端真实网络；有方向、极性、脚号或电源域时明确说明 |
| 怎样起作用 | 对电流、电压、电平、时序或信号的具体作用，以及发生的条件 |
| 为什么这样选 | 关键阻值/容量/耐压/频率等的作用和有证据的选值依据；无需抄满数据手册 |
| 正常应该是什么状态 | 正常电压、逻辑有效电平、默认装配/跳线位置、启动或工作条件，适用时注明 |
| 使用时注意什么 | 反接/短接/开路/漏装影响，调试测量方法和重要操作限制，按实际适用项写 |

至少明确位号、具体用途和真实连接，再补充与该器件有关的参数及状态。已知但关键的条件不能省略；不适用项无需凑字数。解释不确定时写“待核实：具体问题及其影响”，不能填入猜测的门限、电压、功率或手册保证。

推荐注释结构：

```text
位号｜具体功能
连接：输入/上游网络 → 本器件 → 输出/下游网络，或两端网络与相关引脚。
作用：说明在什么条件下，对哪个实际问题产生什么作用。
参数与状态：关键值的用途、默认装配/正常状态；必要时附选值依据。
调试与注意：应该测哪里、不能怎样连接、漏装/错装的具体影响。
```

模板是内容提示，不要求每个小电阻机械地显示五行标题。可以写成两三句紧凑说明，但不能丢掉读者理解此器件所需的信息。

## 各类器件的必查说明

| 器件 | 注释需要具体到什么程度 |
|---|---|
| 上拉/下拉电阻 | 哪条信号、拉向哪个电源域/地、默认逻辑、由谁驱动、启动采样/开漏释放关系及阻值作用 |
| 串联电阻/零欧电阻 | 串在哪条路径，是阻尼、限流、隔离、选配还是测流入口；默认是否装配、允许何种替代 |
| 分压电阻 | 上下臂分别是谁、输入与采样网、分压关系、适用输入范围；无依据时不承诺量程安全 |
| 去耦/储能电容 | 哪条电源、服务哪个器件/电源脚、输入侧还是输出侧、高频旁路还是储能；不能统称“滤波” |
| 补偿/定时/晶振负载电容 | 与谁形成补偿/延时/振荡条件、关键参数作用和是否待调；不能误写成普通去耦 |
| 电感/磁珠 | 功率储能还是噪声隔离、输入输出网络、负载及关键电流/阻抗约束；磁珠不当稳压器解释 |
| 二极管/瞬态保护器件 | 极性、保护对象、正常/异常导通条件、钳位或续流路径，以及参数依据 |
| 发光二极管及限流电阻 | 对应哪条电源/状态、何时亮、极性与限流作用；电源灯不能写成固件运行灯或短路判定器 |
| 场效应管/三极管 | 各极/脚连接、开关或控制角色、驱动来自哪里、工作条件和参数未确认项 |
| 稳压器/电源管理芯片 | 每路实际使用/未使用输出、输入与输出、使能、反馈、复位、保护、关键外围配合及启动条件 |
| 微控制器/复杂芯片 | 本设计任务、供电域、时钟、启动配置、复位、下载与正在使用的接口，按功能块解释而非只写“主控” |
| 运放/比较器/传感器 | 输入输出、供电、反馈/增益/阈值、量程与实际用途，注明输出方向和必要限制 |
| 晶体/振荡器 | 有源或无源、频率、信号脚与地/电源脚、负载电容关系和需要核实的配置 |
| 连接器 | 对接对象/观察方向、逐针或明确针组功能、供电方向、电压域、极性及保留/悬空脚用途 |
| 跳线/焊接桥/开关 | 每个触点网络、默认状态、各位置对应模式、禁止组合、是否应断电操作 |
| 测试点/示波器触点 | 测什么真实信号、相对哪个地、正常参考范围或待测目标、接触方式与重要测量限制 |
| 安装孔/机械器件 | 尺寸、金属化与否、是否电气接地/悬空、螺钉及周边禁布目的 |
| 电源标志/未连接标志 | 属于绘图/规则检查语义，不是实体电源或实体器件；关键特殊用法需在本页说明 |

表格用于防漏，不是可原样粘到每个器件旁的最终说明。最终文字必须代入当前真实位号、网络、数值与用途。

## 正反例

以下是写法示例，位号、网络和数值均为演示假设，不能当作任何项目的实际连接或直接套用。使用前从当前根网表和资料核实。

| 含糊注释 | 具体注释示例 |
|---|---|
| R3：上拉 | R3（10kΩ）将低有效复位信号RESET_N上拉到3V3。复位源释放开漏输出后，由它建立高电平；与复位网上总电容共同影响上升时间，需满足目标芯片复位释放条件。 |
| C11：滤波 | C11（100nF）跨接U3的数字电源3V3与GND，为U3该电源引脚提供就地高频旁路，减小开关瞬间的供电扰动；布局应缩短电源脚—C11—地的回路。 |
| C8：电容 | C8是稳压器U1输出侧的储能/稳定性电容，连接VOUT与GND；其有效容量及等效串联电阻需落在U1规定窗口，漏装可能影响输出稳定。具体范围应依据所选型号填写。 |
| JP1：模式选择 | JP1的1脚接GND、2脚接MODE、3脚接3V3；默认短接1—2，使MODE为低电平进入模式甲。短接2—3选择模式乙，禁止三脚全短，以免短路3V3与GND；切换前断电。实际模式名称应换成手册定义。 |
| TP2：测试点 | TP2接内核电源CORE_SUPPLY，相对附近GND测量；用于确认上电后的核心供电是否建立及是否有异常纹波。目标电压/允许范围从当前器件工作条件填写，不能凭网名猜测。 |
| J3：下载口 | J3用于连接具体型号下载器，说明接口协议、针序、目标参考电压、地和复位；必须逐针标明电源脚是检测输入还是供电输出，并写清外供/板供选择，不能只标“3V3”。 |

示例中提到“需填写/核实”的内容，在正式交付中应补齐，或明确列为待确认项，不能把半成品模板当完成注释。

## 芯片与回路需要两层说明

对于微控制器、电源管理芯片等复杂器件，先有器件总说明，再在实际用到的功能块旁说明：

1. 总说明：它在本板承担的任务，上下游是谁，主要电源与控制关系。
2. 分块说明：各供电域和旁路、启动配置、时钟、复位/错误、下载、接口等；说明真实引脚/网络、正常行为与关键默认值。
3. 外围器件说明：上拉、补偿、定时、去耦、跳线等仍需明确对应位号，不因芯片旁有长说明就视为外围已覆盖。

连接器或芯片针表若已完整准确说明某组引脚，可引用对应针表；仍应写清器件/针组用途和重要连接限制。未使用的输出/引脚写明真实处理和原因；不能编造“备用”用途，也不把保留、悬空、禁止连接和接地混成一类。

## 重复器件与几乎逐器件覆盖

允许合并完全相同功能的重复器件，但必须满足：

- 明确列位号；连续范围只有在当前范围内所有器件均存在且功能相同时才能使用。
- 每个器件都能从注释反查到自身用途、网络和服务对象。多电源域、不同被旁路引脚可用表格列出对应关系。
- 不同值、输入/输出侧、定时/旁路、默认装配状态或职责的器件分开说明。
- 不接受一句“所有电容用于滤波”覆盖整页，也不按距离把附近所有元件算作已注释。

例如同一数字电源的重复旁路可写“C11、C12各100nF，分别服务U3的VDD1、VDD2，跨接3V3—GND”，再给相应连接/回路说明；若C13属于模拟参考或核心稳压输出，则必须另写。

无需为每一个重复GND符号、全局标签、结点和导线写一张器件说明，它们不是独立实体器件。特殊电源标志、未连接策略可集中说明。不能以此豁免实际电阻、电容、测试点、机械孔和其它有用途的器件；例外需在覆盖清单中说明。

多单元芯片按物理位号统计一次，但各已用单元的不同功能都要有对应说明。库里的符号定义不计成已放置实例。

## 必须写在原理图里，且读得清

- 优先使用非电气文字/文本框，靠近对应器件或功能块，或用清楚的位号索引关联到本页说明区。
- 不能只修改隐藏的说明属性、BOM、外部报告或聊天；这些可补充，不能替代图内可见中文解释。
- 注释不要用全局/层次/本地网络标签代替，不能为了排版增加电气结点或改变网名。
- 位号、器件值、脚号和网络标签保持可见；文字不压连线、符号和其它说明，不让注释连线看似电气导线。
- 页内空间不足时按功能调整非电气排版/画幅；必要时用清楚的位号表关联说明页。不能把字号缩到不可读，或将全部详细内容移到图外。
- 正常图纸缩放/导出阅读时应能辨认中文与单位。检查所用字体能显示中文、换行完整、无裁切与叠字；导出成功不代表版面通过。
- 用户限制不许移动符号时，只安排文字/说明区，不借加注释移动器件或重画电气连接。

## 编辑和校验流程

1. 从当前根网表和各实例页取得实际器件集合、用途、值、网络、DNP/装配状态；不从旧BOM抄位号。
2. 建注释覆盖清单，至少含位号、层次页/单元、实际网络、注释所在页/文字对象或可定位文本、分组关系、待确认项和例外原因。
3. 用当前手册/设计输入确认功能和关键条件，再写中文解释。无法确认的就标具体待确认问题；不把典型参数当保证值。
4. 在授权源页增加或修改非电气文字；保留现有合理注释，修正与实际连接不符的旧说明，避免重复或矛盾。
5. 纯注释修改前后比较根网表：组件集合、值、封装、逐引脚网络及关键元数据不应变化；只有明确获授权的可见注释属性可列作元数据例外。
6. 导出并比较电气规则检查结果；新增文字不应引入电气变更。导出SVG/PDF等可用原生视图检查中文显示、覆盖关联和版面，不使用computer-use。
7. 人工逐项核对内容是否解释了**本电路里的具体作用**。文字存在、字符数足够或包含位号，只能证明存在，不能自动证明说清楚了。
8. 对照全部实际位号验收，列总数、已覆盖、缺漏、合理例外与待核实内容。任务范围未完成要如实列出，不能靠统计标签/电源符号提高覆盖率。

纯注释修改不应改变PCB、布线、器件值、封装或网络，也不需要同步PCB。完成报告说明注释覆盖范围与证据；不能把此技能规范的更新说成已经给用户现有工程逐器件补完注释。
