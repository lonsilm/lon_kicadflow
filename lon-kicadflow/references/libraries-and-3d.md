# 符号、封装、测试结构与3D模型

## 可迁移的库

工程本地库优先，放在 `libraries/`、`models/`，通过 `${KIPRJMOD}` 引用；标准官方库可使用本机有效版本变量。不要把另一台电脑的盘符写进新工程。

```scheme
(sym_lib_table
  (lib (name "ProjectSymbols")(type "KiCad")
    (uri "${KIPRJMOD}/libraries/ProjectSymbols.kicad_sym")
    (options "")(descr "Project-local symbols")))

(fp_lib_table
  (lib (name "ProjectParts")(type "KiCad")
    (uri "${KIPRJMOD}/libraries/ProjectParts.pretty")
    (options "")(descr "Project-local footprints")))
```

保留已有库表条目、说明和schema；上例不是替换全表的指令。符号 `Library:Name`、封装 `Library:Footprint` 的库昵称需与表一致。一个 `.pretty` 文件夹内每个 `.kicad_mod` 是一个封装，不把整个目录塞进单个文件。

迁移核对：库表可解析、文件存在、继承符号父定义可解析、模型存在、无无意绝对路径、许可证允许携带。全局库表与项目库表作用域分开，不为一个项目覆盖全局库。

## 自制符号

依据原厂pin表和封装图，记录具体料号/封装变体/手册版本。大BGA按功能拆unit：电源地、启动调试、外设、模拟等；保留全部脚号，标明复用功能而非把一个球复制成多个独立电气脚。

- pin number为连接身份，pin name是说明；二者不能互换。
- 电源脚的电气类型、隐藏电源脚、NC/DNC、裸露焊盘逐项核查；DNC不等于可接地。
- 验证符号脚号集合与原厂表的双向差异，检查重复脚号是否为合理堆叠。
- 新器件属性包括完整值、封装、datasheet、MPN、采购编号（若确定）和来源，不把模糊商品名当确定料号。
- 对大器件建议生成逐球CSV/JSON，记录原厂页码、供电域、复用与使用状态，再从网表核对实际分配。

## 自制/修正封装

证据顺序：原厂recommended land pattern→准确机械图→官方KiCad库→核实后的分销商/EDA库。不能因某个模型看起来对就认定焊盘对。

核对项目：

| 类别 | 必查内容 |
|---|---|
| 尺寸 | 脚距、行距、焊盘长宽、钻孔、焊环、器件最大外形和公差 |
| 编号 | 1脚方位、顺时针/逆时针、奇偶列、顶视/底视、连接器配合面视图 |
| 图层 | F/B.Cu、Mask、Paste，丝印不压焊盘；测试铜盘通常不需要锡膏 |
| 制造 | 阻焊桥、钢网开口、热焊盘分窗、孔径与金属化类型 |
| 装配 | Courtyard闭合、F.Fab外形、原点、器件质心、方向与装配间隙 |
| 电气 | 逐脚号网名、裸露焊盘、多个同号铜盘的合理性 |

原理图引用封装ID、库里的定义、PCB内嵌实例是三份状态。改库不自动改板；更新PCB实例会改变焊盘几何与铜线端点，应按授权范围执行并复核。焊盘UUID、路径身份和位置保留也不代表旧走线仍接对脚。

### 排针/排母与BTB

完整型号确认公/母、节距、针数、行数、直式/卧式、SMT/THT、塑胶高度和配对高度。下载器用排针不能因模型只找到排母就替代。DF40等BTB两半观察方向可能相反，3D资源的编号约定不能覆盖设计脚号。

替换后检查旧铜线是否碰到新的另一脚。典型风险是奇偶列换位后旧8/10脚引线接触新7/9脚；保持相同网络属性也不能消除几何短路。

### 金属化安装孔

M3螺钉常见间隙孔3.2mm，但按螺钉/机械要求选择。用户要求金属化就采用PTH带铜盘，不是NPTH。铜盘外径、螺丝头/垫圈禁布、电气接地或NC分别确定；不擅自把机械孔接地。

只授权原理图时，放符号并绑定封装，不在PCB上自动放四个孔。已有板上机械孔同步时检查路径/位号关联，避免重复增加。

### 小测试点

分清实际探针接触、人工焊线、量产针床三种要求；越小越难接触，不只追求视觉紧凑。裸铜点常用SMD圆盘、Cu+Mask，无Paste、无实体件/采购量；丝印/外框可放到Fab或注释层，避免额外占地。

双接触示波器结构可建为一个两脚器件：1=信号、2=GND，分别独立焊盘；以用户探头中心距、盘半径/直径为准。**半径0.3mm意味着直径0.6mm**，不能弄反。某项目采用3mm中心距仅为案例，不是示波器通用标准。保证探头操作不会跨接邻近高压/开关节点。

### 紧凑焊接跳线

区分0Ω电阻、双针插帽、常开锡桥、常闭切断桥。用户要0402大小的手工锡桥时，明确总铜区、两个焊盘、缝隙、阻焊与锡膏策略；不直接使用普通0402电阻焊盘并承诺易焊。

常开两铜盘间不能有铜桥，通常不出锡膏，BOM标手工加锡。默认短接/开路在原理图注释和装配说明一致，不依赖用户猜。

## 3D模型取得

优先顺序：官方KiCad对应资源→制造商STEP→可信分销商/CAD库→嘉立创EDA/EasyEDA对应准确料号资源→有来源的简化自建模型。利用可用连接器/API/直接下载能力，不要求computer-use。

取得过程必须核对：

1. 精确MPN和封装后缀匹配；不同引脚数/高度/外形的同系列不能混用。
2. 资源确为STEP/STP/WRL数据，检查文件头、下载类型和合理体积，不把HTML错误页改后缀当模型。
3. 嘉立创商品页、LCSC号、EasyEDA设计UUID和3D UUID是不同标识，记录对应关系；接口可能变化，先核当前公开结构，不永久硬编码临时下载链接。
4. 有复用限制时保留来源/许可。模型仅用于装配时无需导入其封装焊盘。
5. 无法取得准确模型时说明缺失或采用可辨识的简化外形，不冒充原厂精确STEP。

## 绑定、变换与验收

典型模型节点：

```scheme
(model "${KIPRJMOD}/models/Part.step"
  (offset (xyz 0 0 0))
  (scale (xyz 1 1 1))
  (rotate (xyz 0 0 0)))
```

单位、原点与旋转顺序按KiCad版本/模型文件实际验证。WRL历史资源可能有单位差异；不要未经量测就套25.4或2.54缩放。背面器件通常由KiCad根据封装面翻转，不能为“看起来反了”重复镜像。

- 先在库封装或授权的隔离副本对齐原点、焊盘和外形；量关键长宽高，验证正反面、1脚、引脚接触高度。
- 如果只允许PCB模型属性，变化集合限 `model` 节点的路径/旋转/缩放/偏移。对移除模型节点后的源文本/AST作比较，保证其它焊盘、net、轨迹、摆放没有变化；哈希本身会因模型变动而改变，不能用“哈希相同”验收这类授权修改。
- 原生读回确认，按本机 `pcb export render/step --help` 可用能力导出装配视图或STEP。渲染成功不等于碰撞/净空通过。
- 查底部BTB配合高度、螺钉/垫圈、晶振/电感/电解高度、元件互撞和连接器插拔空间。
- 只写库和源指派时明确PCB模型尚未更新，不能说所有板上模型已导入。

3D修正不是自动更新全部封装的理由。若API序列化会丢失非模型属性，应在隔离副本验证，采用能够证明范围的最小修改，遵守根PCB的现有限制。
